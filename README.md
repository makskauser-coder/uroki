# Уроки для 3 класса

Интерактивные страницы-уроки. Ребёнок слушает объяснение голосом, вписывает ответы
прямо на странице и сразу видит, где ошибка и как считать правильно. Когда задание
сделано верно — открывается чистовик для переписывания в тетрадь.

## Общие файлы

* `assets/uroki.js` — учёт **первой попытки** по каждому заданию, замок после ошибки
  («Понятно — пробую ещё раз»), итоговая карточка урока и сохранение прогресса
  в `localStorage` под ключом `uroki.progress.v1`.
* `assets/lesson.js` — движок уроков: карточки упражнений и виджеты с проверкой
  (числовой ответ, текст, выбор варианта, окошки-списки, разметка членов предложения,
  выбор слов, составление предложения, разбор по составу, свободный ответ),
  чистовик и озвучка (Web Speech API).
* `assets/lesson.css`, `assets/uroki.css` — общий вид.

Главная `index.html` сама собирает список по предметам из массива `CATALOG`
и рисует галочки по сохранённому прогрессу.

## Как добавить тему

1. Скопировать любой урок (например `matematika-47.html`) как образец.
2. Задать свой `Lesson.start({id, title, subject, lang})` — `id` должен быть уникальным.
3. Описать упражнения через `Lesson.ex()` и виджеты.
4. Добавить строку в `CATALOG` в `index.html`.
5. `git add -A && git commit -m "..." && git push` — сайт обновится сам.
