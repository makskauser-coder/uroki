# Уроки для 3 класса

Две интерактивные страницы-урока: математика (деление двузначного на однозначное,
урок 46) и беларуская мова (даданыя члены сказа, практыкаванні 124–129).

Ребёнок слушает объяснение голосом, вписывает ответы на странице и сразу видит,
где ошибка и как считать правильно. Когда задание сделано верно — открывается
чистовик для переписывания в тетрадь.

Опубликовано через GitHub Pages: содержимое папки отдаётся как есть,
никакой сборки не нужно. Чтобы обновить урок — поправить html и сделать push.
